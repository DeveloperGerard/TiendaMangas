# 🎨 Guía de Diseño: HunterForMangas

## 1. Contexto del proyecto

Estoy desarrollando un proyecto llamado **HunterForMangas**, una aplicación web relacionada con la organización y visualización de mangas.

Quiero que mejores visualmente los archivos `base.html` y `base.css`, que funcionan como estructura y hoja de estilos base del proyecto.

## 2. Referencia visual

Utiliza como principal inspiración el diseño visual de **Hunter x Hunter**.

Busco una estética:
- Minimalista y sencilla.
- Limpia, ordenada y elegante.
- Inspirada en la identidad visual de Hunter x Hunter, sin copiar literalmente sus interfaces.
- Con una apariencia de biblioteca digital de manga.
- Sin elementos decorativos innecesarios ni exceso de colores.

## 3. Paleta de colores

Utiliza una combinación equilibrada de:
- Verde inspirado en Hunter x Hunter como color principal.
- Blanco y tonos ligeramente cálidos para los fondos.
- Gris oscuro para textos principales.
- Gris claro para bordes y separadores.

Evita colores demasiado saturados, degradados llamativos y sombras excesivas.

## 4. Lineamientos de diseño

- Prioriza el espacio en blanco y una buena distribución de los elementos.
- Utiliza bordes sutiles y esquinas ligeramente redondeadas.
- Mantén una jerarquía visual clara entre títulos, subtítulos y contenido.
- Utiliza una tipografía moderna, legible y consistente.
- Diseña una navegación sencilla y discreta.
- Mantén una apariencia visual coherente en toda la aplicación.
- Asegura que el diseño sea responsive para móviles, tablets y escritorio.

## 5. Instrucciones de implementación

- Trabaja directamente sobre `base.html` y `base.css`.
- Conserva las clases CSS, identificadores, nombres de atributos y selectores existentes.
- No elimines ni renombres elementos que puedan estar siendo utilizados por Django, JavaScript u otras plantillas.
- No alteres las etiquetas de Django (`{% block %}`, `{% extends %}`, `{% load %}`, etc.).
- No modifiques la lógica ni la funcionalidad existente.
- Puedes mejorar la estructura HTML cuando sea necesario, siempre que mantengas su compatibilidad.
- Organiza el CSS y evita reglas duplicadas o innecesarias.
- Utiliza variables CSS para centralizar colores, tipografías y otros valores reutilizables.

## 6. Resultado esperado

Quiero un diseño visual profesional, minimalista y agradable, inspirado en Hunter x Hunter.

**Prioridad:** mejorar la presentación visual de la estructura existente sin cambiar su funcionamiento. No quiero una reconstrucción completa ni una interfaz sobrecargada; quiero una decoración coherente, sencilla y bien ejecutada.
